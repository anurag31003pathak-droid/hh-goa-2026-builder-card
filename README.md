# 🌴 Hacker House Goa 2026 — Builder ID Generator

> **Turn your profile into a Builder Pass. ⚡**

A creative web tool built for the **Hacker House Goa 2026** shortlisting task.

Upload a photo, customize your builder identity, choose a Goa-inspired style, and generate a share-ready **Builder ID Card** in seconds.

🔗 **Live Demo:** https://hh-goa-2026-builder-card-bay.vercel.app/

---

## ✨ What is it?

The **Hacker House Goa 2026 Builder ID Generator** is a browser-based creative tool that transforms a simple photo and builder profile into a personalized event-style Builder ID Card.

The idea was to combine:

**🌴 Goa vibes + ⚡ Hacker culture + 🛠️ Builder identity**

into something that feels fun, personal, and worth sharing.

---

## 🚀 Features

* 📸 Upload JPG, PNG and HEIC photos
* 🎨 Goa-inspired card themes
* 🌅 Beach, sunset and tropical backgrounds
* 🪪 Multiple Builder ID card layouts
* ✏️ Customize name, role, handle and builder title
* 🛠️ Add your technology stack
* 🔍 Photo zoom and positioning controls
* 🎭 Multiple visual styles
* ⚡ Live card preview
* 🖼️ Client-side image generation
* 📥 Download the generated card as PNG
* 𝕏 Share directly to X
* 📱 Fully responsive and mobile-friendly
* 🔐 No login or signup required
* 💾 No permanent photo storage

---

## 🎨 Builder Card

The generated card is designed as a social-first event credential rather than a traditional ID card.

It includes:

* Hacker House Goa 2026 branding
* Builder photo
* Name
* Role
* Builder title
* Technology stack
* Builder ID
* Event information
* `#FrameInGoa`

The card can be exported in multiple social-friendly formats.

## 🎯 Why I Built It

I wanted to experiment with building a small product where **design and functionality work together**.

Instead of creating another basic form-based application, I focused on making the experience feel like a mini creative editor — something users can play with and immediately get a visual result from.

The biggest design inspiration was:

> **What would a Hacker House builder pass look like if Goa was part of the identity?**

---

## 📱 Responsive Design

The experience is designed for both desktop and mobile.

On desktop:

* Editor + live preview layout
* Large Builder Card preview
* Advanced customization controls

On mobile:

* Stacked editor
* Touch-friendly controls
* Responsive preview
* Easy download/share actions

## 🔒 Privacy
